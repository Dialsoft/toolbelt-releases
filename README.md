# Tool Belt

A launcher bar for Windows 10 and 11 that docks across the top of the screen, like a
second taskbar, with 12 slots for the tools you use every day. By Dialsoft LLC.

**Product page, guide and video:** https://dialsoft.com/toolbelt/

## Download (version 1.2.0)

| File | What it is |
|---|---|
| `ToolBeltSetup.exe` | **Installer** (recommended). Installs just for you, no administrator password. Options to start with Windows and add shortcuts. |
| `ToolBelt.exe` | **Portable** single program. Nothing to install: put it anywhere and double-click it. |
| `USER-GUIDE.html` | The user guide (also built into the program: belt menu > User guide). |
| `toolbelt-explainer.mp4` | Short explainer video. |
| `RELEASE_NOTES.txt` | What changed in each version. |
| `*.sha256` | Fingerprints to check a download is genuine and complete. |

## Where updates come from

Installed copies of Tool Belt update themselves from **dialsoft.com/toolbelt/latest.json**,
not from this page. This repository is a public copy of each release, kept as a backup
and as a second place to download from. `latest.json` here is a copy of that feed.
